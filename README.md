# 幸福水屋 業務培訓站

給業務內部使用的培訓網站：品牌故事、方案比較、營業額試算、AI 問答專區。

## 網頁結構

| 檔案 | 內容 |
|---|---|
| `index.html` | 品牌故事（隱形商機／總部痛點／陪跑方案解法／隱形冠軍／風險透明化） |
| `compare.html` | 兩方案完整比較、分層流程圖、退約試算範例 |
| `calculator.html` | 營業額試算器（含走勢圖） |
| `qa.html` | 問答專區（常見問題庫 ＋ 即時 AI 問答） |
| `knowledge.md` | AI 問答的知識來源，彙整所有方案細節與話術原則 |
| `server.js` | 靜態網頁伺服器 ＋ `/api/ask` AI 問答後端 |
| `assets/` | 共用樣式、logo、通路實績圖、機台實照 |

## 怎麼讓大家試用（需要你自己申請一組 Anthropic API key）

這個網站的 QA 頁如果要「真的能問答」，需要一個能保管 API key 的後端——API key 不能直接寫在
網頁（qa.html）裡，不然任何人打開網頁原始碼都看得到、會被盜用。`server.js` 就是這個後端，
負責保管 key 並代替前端呼叫 Claude API。

### 本機測試步驟

1. 安裝 [Node.js](https://nodejs.org)（建議 18 以上版本）。
2. 在這個資料夾打開終端機，執行：
   ```
   npm install
   ```
3. 到 [console.anthropic.com](https://console.anthropic.com) 申請一組 API key。
4. 複製 `.env.example` 為 `.env`，把 `ANTHROPIC_API_KEY` 換成你自己的 key。
5. 啟動伺服器：
   ```
   npm start
   ```
6. 瀏覽器打開 `http://localhost:3000`，就能看到完整網站，QA 頁的問答框會真的呼叫 AI 回答。

### 想讓外部的人（例如遠端的業務）也能連進來測試

本機測試只有你自己的電腦連得到。如果要讓其他人透過網址連線，需要把這個資料夾部署到一台
有公開網址的主機，常見的免費／低成本選項：

- **Render / Railway / Fly.io**：都支援直接部署 Node.js 專案，把這個資料夾上傳或連結 Git repo，
  在後台環境變數設定 `ANTHROPIC_API_KEY` 即可，不用改任何程式碼。
- **公司自己的雲端主機**：把整個資料夾放上去，跑 `npm install && npm start`（建議搭配 `pm2` 讓服務常駐）。

不管哪種方式，重點都是：**API key 只放在伺服器的環境變數裡，絕對不要寫進 qa.html 或任何前端檔案**。

## 如果 QA 頁看起來連不上 AI

qa.html 會顯示「連不上 AI 服務」，代表 `server.js` 沒有在跑，或是 `.env` 裡沒有正確的 API key。
這時候上方的問答庫（分類篩選＋手風琴列表）還是可以正常使用，只是不會即時生成新答案。

## 之後要更新方案內容時

只要改 `knowledge.md`（文字檔，直接編輯即可），改完重新啟動伺服器，AI 的回答依據就會跟著更新，
不需要碰程式碼。網頁上的靜態內容（品牌故事、比較表、試算公式）如果也要跟著調整，記得同步修改
對應的 `.html` 檔案，避免網頁顯示的內容跟 AI 回答的內容兜不起來。
